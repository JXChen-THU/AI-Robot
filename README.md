### 怎么用（下载后 3 步）

1. 下载/克隆这个仓库
2. 按 [docs/02](docs/02_环境搭建.md) 装好环境，把 [config/User_Setup.h](config/User_Setup.h) 覆盖到 TFT_eSPI 库目录
3. 用 Arduino IDE 打开 `firmware/01_display/01_display.ino` → 编译 → 烧录 → 按 [docs/03](docs/03_分步测试指南.md) 一关一关走

> **注意**：每个 `firmware/xx_*/` 目录里的 `pinmap.h` 是从 `firmware/_shared/pinmap.h` **自动复制**的副本（Arduino IDE 要求同目录有头文件）。
> 改引脚只改 `_shared` 那一份，然后跑 `tools\sync_pinmap.ps1` 同步，**不要单独改副本**。

## 三分钟看懂核心设计

这是一台**引脚被用到极限**的机器人：

- 这块板 45 个 GPIO 里，26–32 给 Flash、33–37 给 8MB PSRAM、0/43/44 给按键和串口、19/20 给 USB。
- **真正能用的干净引脚只有 25 个**，连上 3/45/46（启动脚，安全用法）+ 19/20（放弃 USB 口）才凑到 **30 个**。
- 而 7 个模块按"常规接法"要 39 个引脚 —— **根本装不下**。

所以本方案做了 4 个关键取舍（详见 [docs/01](docs/01_接线总表.md) 第 1.3 节）：

| 取舍 | 省下的引脚 |
|---|---|
| 屏幕 RST / 背光直接接 3V3 | 2 |
| 摄像头 RST 接 3V3、PWDN 接 GND | 2 |
| 麦克风和功放**共用** BCLK/WS（分时复用：录的时候不播，播的时候不录） | 2 |
| TB6612 的 PWMA/PWMB 接死 3V3，用**方向脚直接吃 PWM** | 2 |

**最终 30 个引脚全部用满。** 唯一的余量是 **GPIO 12**——因为本项目的摄像头自带晶振，不需要 ESP32 给它时钟（XCLK），这个脚就空出来了，可以留给以后加蜂鸣器/按键。想再扩功能看 [docs/01](docs/01_接线总表.md) 第 8 节的三个备用方案。

## 选型要点（想复刻的话看这里）

这套方案是**按引脚预算倒推**出来的，选件时这几条不能变，换一件就要重算：

| 部件 | 硬性要求 | 为什么 |
|---|---|---|
| 主控 | ESP32-S3 **必须带 PSRAM**（N16R8 / N8R8 / N16R2 都行） | 摄像头帧缓冲 + 录音缓冲都放 PSRAM；无 PSRAM 版本跑不动 |
| 屏幕 | 驱动必须 **ST7789**，240×320，SPI 8~10P 无触摸 | 换成 ILI9341 要改 `config/User_Setup.h` |
| 摄像头 | 标准 **DVP 并口** OV2640（有 PCLK/VSYNC/HREF/D0~D7 就行，XCLK 可有可无） | SPI/串口版摄像头用不了 |
| 电池座 | 必须有 **5V 稳压输出排针**（不能是 7.4V 直出） | 7.4V 直接进模块会烧 |
| 驱动 | TB6612FNG（**PWMA/PWMB 可接死 3V3**） | 省 2 个引脚 |
| 杜邦线 | **20cm 母对母 + 10cm 母对母 + 20cm 公对母**，24AWG 铜芯 | 摄像头/电机/电源要 20cm；近处用 10cm；舵机必须公对母 |
| 万用表 | 数字万用表，**带蜂鸣通断档** | 上电前查短路、查线通断，一项都不能省 |

**明确不需要买**：烧录器（板子自带 USB 串口）、电平转换模块（超声波供 3.3V 就绕开 5V 问题）、面包板、第二块主控。

### 唯一需要你核对"型号对不对"的地方（不是换，是确认）

收到货后核对这三处丝印（对照 [docs/06](docs/06_到货核对单.md)）：

| 位置 | 要确认什么 | 不对会怎样 |
|---|---|---|
| 屏幕背面 | 驱动芯片是不是 **ST7789**（不是 ILI9341 / ST7789V2） | 是别的型号要改 `config/User_Setup.h` 两行 |
| 主控板上 | 模组丝印是不是 **ESP32-S3-WROOM-1 N16R8** | 若**不带 R**（无 PSRAM）或 **MINI 版**，摄像头/录音会跑不动 → 这种才需要换板 |
| 电池座 | 输出排针是不是标 5V / 3V3 | 没有稳压输出的板子不能用（会 7.4V 直出烧模块） |

> 只要主控是 **N16R8（或 N16R2/N8R8 都可）**、屏幕是 **ST7789**、电池座有 **5V 稳压输出**，就直接开工，不需要换任何东西。

## 现在该做什么

### 如果你还没收到货（大概率现在）

1. **先做 [docs/02_环境搭建.md](docs/02_环境搭建.md)** —— 装 IDE、装 ESP32 包、装 4 个库、替换 TFT_eSPI 配置。这一步不需要硬件。
2. 顺手准备三样东西：**万用表**（20 元，救命用）、**一个 5V/2A 的 USB 电源**（调试时用，不用电池）、**手机支架**（当遥控器）。
3. **别急着接线。** 按 [docs/01](docs/01_接线总表.md) 把每根线的去向先在纸上标一遍。

### 收到货后

4. 核对并记录：① 板子正反面丝印 ② 屏幕背面型号 ③ 电池座的丝印/拨码开关。**不同批次的模块引脚定义可能不一样**，先对照 [docs/01](docs/01_接线总表.md) 第 3 节确认，再插电。
5. 用万用表通断档确认电池座输出是 5V 和 3.3V（别直接相信丝印）。
6. 严格按 [docs/03_分步测试指南.md](docs/03_分步测试指南.md) 一关一关过，**不要一次全接上**。

## 安全须知（真的会烧东西）

1. **3.3V 器件绝不进 5V**：摄像头、麦克风、屏幕 VCC、TB6612 的 VCC。
2. **HC-SR04 供 3.3V**，否则 ECHO 的 5V 会打进 ESP32-S3 引脚（它不耐 5V）。
3. **18650 没有保护板**：两节方向必须一致，别装反；别把电放到 3.0V 以下。
4. **第一次上电把车架空**，手上留着电池开关。
5. **1000µF 电解电容正负极别接反**（反接会鼓包甚至炸开）。
6. 烧录用 **UART 口**那颗 Type-C，`USB` 口平时别插（那两个脚被超声波用了）。

## 云端对话怎么工作

```
你按住 BOOT 键说话
   ↓ INMP441 录 3 秒 → PSRAM
   ↓ WiFi → 百度智能云 ASR（语音转文字）
   ↓ WiFi → 大模型（默认 DeepSeek，OpenAI 兼容接口）
   ↓ 返回："好的，我往前走了|FORWARD"   ← 文字 + 动作指令
   ↓ 百度智能云 TTS（文字转语音，mp3）
   ↓ ESP32-audioI2S 解码 → MAX98357A/喇叭
   ↓ 同时 TB6612 执行 FORWARD（带软启动 + 避障保护）
```

申请 Key 的详细步骤见 [docs/05_云端语音与大模型.md](docs/05_云端语音与大模型.md)。
两个后端都写好了，改一个 `#define` 就能切换：
- **后端 1（默认）**：百度智能云（ASR + TTS）+ 任意 OpenAI 兼容大模型 —— ASR/TTS 都有免费额度
- **后端 2**：硅基流动 SiliconFlow —— **一个 Key 同时搞定 ASR + 大模型 + TTS**，最省事
