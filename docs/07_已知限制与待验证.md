## 二、已知限制（不是 bug，是设计取舍）

### 1. 引脚用到了极限：30 个全满，只剩 GPIO 12

7 个模块按常规接法要 39 个引脚，这块板只有 30 个可用。为了装下全部模块，做了 4 处取舍（详见 [docs/01](01_接线总表.md) 1.3 节）。

- **想加新功能**：先用 **GPIO 12**（本项目摄像头自带晶振，XCLK 脚空着）。
- **还要更多**：只能砍模块，或用 [docs/01](01_接线总表.md) 第 8 节的备用方案（单线超声波 / 去掉屏幕 / PCA9685）。

### 2. 5V 电流是有上限的

DFRobot 双 18650 板的 5V 输出要同时供：ESP32 + 4 个电机 + 2 个舵机 + 功放。

因此固件里做了三件事：**PWM 限 62%**、**软启动**、**避障强制停车**。
**不要**让它"四轮全速 + 双舵机同时扫动"，会触发欠压重启（表现为莫名其妙重启）。1000µF 电容只能垫几毫秒。

### 3. 麦克风和功放共用 I2S 时钟线

为了省 2 个 GPIO，两者共用 BCLK/WS，靠**分时复用**（录时不播、播时不录）。

- 副作用：**录音时喇叭会发出极轻微的"咔咔"声**，正常现象。
- 代价：录放切换有约 100ms 的开销，语音反应会比纯硬件方案慢一点。

### 4. HTTP 服务是单线程的

- 手机正在看 `/stream` 时，`/capture`、`/status` 打不开（同一个 WebServer 在推流）。
- iPhone Safari 对 MJPEG 支持不稳定，`04_camera` 已做降级：5 秒没画面自动改成每 700ms 拉一张图。
- 网页**没有密码**：同一个 WiFi 里谁打开都能控制小车。**别接到公共/公司 WiFi**。

### 5. 电机编码器没有接

4 个 TT 电机自带码盘（每电机 6 根线），本项目**不接编码器**——没有引脚了，也用不上（没有闭环需求）。
把码盘线用扎带收好即可，不影响任何功能。

### 6. 云端语音是"家用实验"级别

- HTTPS 用了 `setInsecure()`（跳过证书校验），百度 TTS 走明文 http（token 在 URL 里）。
- 只在自家 WiFi 玩没问题；**不要放到公网、不要在公共网络用**。
- API Key 只放在 `secrets.h`（已被 `.gitignore` 排除），仓库里只有模板。

### 7. 舵机没有位置反馈

SG90 是普通舵机，没有回读。代码里用"目标角度 + 逐步逼近"的方式平滑移动，但**断电后位置未知**，上电会先回中位（90°）。

## 三、代码里刻意做的"防御性设计"

这些地方看起来啰嗦，但都是踩过坑才会加的，**改代码前先看注释**：

| 位置 | 为什么这么写 |
|---|---|
| `pinmap.h` 的 `ROBOT_GUARD` | 编译期拦住"把引脚改成 26~37（PSRAM/Flash）"这种致命错误 |
| 每个 sketch 里的 `#error` 检查 | `01_display` 会校验 `User_Setup.h` 的引脚和 pinmap 是否一致，配错直接编译报错，而不是烧进去看白屏 |
| `02_motor` 的软启动 | 电机瞬间全速会让 5V 塌陷、主控重启 |
| `06_sonar` 的 `pulseIn(..., 30000)` | 不加超时会死等 1 秒，整个程序像卡死 |
| `07_main` 的 deadman（1.5 秒） | 手机网页断了/手机锁屏了，车不会一直往前冲 |
| `voice_cloud.h` 录音前 3 次重试 | audio 库偶尔晚释放 I2S，不重试会"第二次说话没反应" |
| `05_audio`/`voice_cloud.h` 显式写 `slot_mask` | 不同 IDF 版本默认值不一样，不写会出现"某声道没声" |

## 四、改硬件时要同步的三步

引脚定义只在**一个地方**：`firmware/_shared/pinmap.h`。

```powershell
# 1) 改 firmware/_shared/pinmap.h
# 2) 同步到所有 sketch
powershell -ExecutionPolicy Bypass -File tools\sync_pinmap.ps1
# 3) 体检（禁区/重复/写死引脚/副本一致性）
powershell -ExecutionPolicy Bypass -File tools\check_pins.ps1
```

第 3 步输出 `ALL CHECKS PASSED` 才算改完。**不要**单独去改 `firmware/01_display/pinmap.h` 这种副本，下次同步会被覆盖。
