# 05 · 云端语音与大模型（申请 Key → 填进去 → 跑通）

> 这一步是整台机器人"有灵魂"的地方。
> 好消息：**ASR（听）和 TTS（说）都有免费额度**，日常玩根本花不到钱。

---

## 1. 先选一条路线

| | 路线 A：百度智能云（默认） | 路线 B：硅基流动 SiliconFlow |
|---|---|---|
| 要注册几个平台 | **2 个**（百度做听/说 + DeepSeek 做脑子） | **1 个**（全包） |
| 免费额度 | 语音识别/合成各有免费额度 | 注册送额度，按量计费 |
| 代码复杂度 | 简单（REST 一把梭） | 中等（ASR 要 multipart、TTS 要存文件） |
| 推荐给 | **第一次做的人** | 已经有 Key 的人 |

代码里两个后端都写好了，改 `voice_cloud.h` 顶部一个 `#define VOICE_BACKEND` 就能切。
**建议先用路线 A 跑通**，确认整条链路没问题，再考虑换。

---

## 2. 路线 A：百度智能云（听 + 说）

### 2.1 注册并实名
1. 打开 <https://cloud.baidu.com/> → 右上角注册（手机号即可）
2. 完成**实名认证**（个人认证，需要身份证 + 人脸，5 分钟）—— 不实名调不了语音接口

### 2.2 开通语音技术
1. 进入控制台 → 搜索"语音技术" → 进入 **语音技术** 控制台
2. 左侧菜单找 **短语音识别**（也叫"语音识别"）→ 点"创建应用"
3. 应用名称随便写（比如 `my-robot`），接口选**短语音识别**，其他默认 → 创建
4. 创建完在"应用列表"里能看到三样东西，**抄下来**：

```
APP_ID     = 12345678
API_KEY    = xxxxxxxxxxxxxxxxxxxx
SECRET_KEY = yyyyyyyyyyyyyyyyyyyyyyyy
```

> 同一个应用里可以同时用"短语音识别"和"语音合成"，**不用建两个应用**。
> 再去左侧菜单点一下 **语音合成**（在线合成），确认它显示"已开通"。

### 2.3 免费额度在哪看
语音技术控制台 → 概览 → 能看到"短语音识别 剩余调用次数"和"语音合成 剩余字符数"。
个人认证一般会送几万次/几十万字符，够你玩很久。

### 2.4 大模型（脑子）用 DeepSeek
1. 打开 <https://platform.deepseek.com/> → 注册 → 充值最低额度（10 元起）
2. 左侧 **API keys** → 创建 → 抄下 `sk-xxxxxxxx`
3. 记下接口地址：`https://api.deepseek.com`，模型名：`deepseek-chat`

> 为什么用 DeepSeek 而不是别家：便宜（一次对话不到 1 分钱）、中文好、接口是 OpenAI 兼容格式，以后想换月之暗面/通义/智谱，只改 `base_url` 和 `model` 两行。
> 不想充钱？用路线 B 白嫖额度，或者先用"本地命令词模式"（见第 6 节）。

---

## 3. 路线 B：硅基流动 SiliconFlow（一个 Key 全包）

1. 打开 <https://cloud.siliconflow.cn/> → 注册（手机号）
2. 左侧 **API 密钥** → 新建 → 抄下 `sk-xxxxxxxx`
3. 三个模型名（在"模型广场"里能搜到，直接抄）：

| 用途 | 模型名 |
|---|---|
| 听（ASR） | `FunAudioLLM/SenseVoiceSmall` |
| 脑子（LLM） | `deepseek-ai/DeepSeek-V3`（或 `Qwen/Qwen2.5-7B-Instruct` 更便宜） |
| 说（TTS） | `FunAudioLLM/CosyVoice2-0.5B` |

4. 接口地址统一是 `https://api.siliconflow.cn`，全部 OpenAI 兼容格式。

> ⚠️ **用路线 B 必须先改一个 IDE 选项**：`Tools → Partition Scheme` 要选 **`16M Flash (2MB APP/12.5MB SPIFFS)`**。
> 因为硅基流动的 TTS 返回的是 mp3 字节流（POST 拿到的，不能像百度那样直接丢个网址给功放播），代码会先把它存进板子的 SPIFFS 文件系统再播放；FATFS 分区里没有 SPIFFS，会直接报挂载失败。
> 路线 A（百度）没有这个限制，选哪个分区都能跑。

## 4. 把 Key 填进代码（★ 千万别填错位置）

1. 打开 `firmware\07_main\` 目录
2. 把 `secrets.example.h` **复制一份**，改名成 `secrets.h`
3. 用记事本打开 `secrets.h`，把引号里的占位符换成你的真实 Key：

```cpp
// WiFi —— 必须是 2.4G 热点，名字别带中文
#define WIFI_SSID       "你的WiFi名字"
#define WIFI_PASSWORD   "你的WiFi密码"

// 路线 A：百度（听 + 说）
#define BAIDU_API_KEY    "你抄的 API_KEY"
#define BAIDU_SECRET_KEY "你抄的 SECRET_KEY"

// 大模型（脑子）
#define LLM_BASE_URL     "https://api.deepseek.com"
#define LLM_API_KEY      "sk-你抄的"
#define LLM_MODEL        "deepseek-chat"
```

> **`secrets.h` 不要发给任何人、不要上传到网上、不要截图发群里。**
> 别人拿到你的 Key 可以刷你的额度。这个仓库里只有 `.example` 模板，不含真实 Key（这是故意的）。

## 6. 没有 Key 也能先玩：本地命令词模式

在 `07_main.ino` 顶部把这行改成 0：

```cpp
#define ENABLE_VOICE 0     // 关掉云语音，只保留：图传 + 网页遥控 + 避障 + 表情
```

这样你依然能：
- 手机看摄像头画面
- 网页按钮遥控前后左右、云台
- 超声波自动避障
- 屏幕表情

先把这些跑顺，再去搞 Key——**不要让"申请 Key"卡住你的进度**。

## 7. 花多少钱（心里有个数）

| 项目 | 单价 | 一次"对话"的消耗 |
|---|---|---|
| 百度短语音识别 | 免费额度内 0 | 3 秒 ≈ 1 次 |
| 百度语音合成 | 免费额度内 0 | 一句话 ≈ 50 字 |
| DeepSeek 大模型 | 约 1~2 元/百万 token | 一次对话 ≈ 200 token ≈ **0.0004 元** |

也就是说：**免费额度内，你随便玩；额度用完后，一天聊 100 句也就几分钱。**

## 8. 报错对照表

| 报错/现象 | 原因 | 解决 |
|---|---|---|
| `[ASR] err_no=3301` | 音频质量差/格式不对 | 检查采样率是否 16000、是否单声道 16bit |
| `[ASR] err_no=3302` | 鉴权失败 | API_KEY / SECRET_KEY 抄错，或没实名认证 |
| `[ASR] err_no=3307` | 音频太长 | 录短一点（≤ 3 秒） |
| `[LLM] HTTP 401` | Key 错 / 没充值 | 去平台确认 Key 和余额 |
| `[LLM] HTTP 402` | 余额不足 | 充值 |
| `[TTS] 没声音但日志正常` | 功放 SD 脚没接 3V3 | 检查 MAX98357A 的 SD 是否接 3V3 |
| `[TTS] 播到一半重启` | 喇叭电流冲击 | 降低音量（代码默认 60%）；加 1000µF 电容（主母线 + 舵机旁） |
| WiFi 一直连不上 | 用了 5G 热点 / 中文 SSID | 换 2.4G、SSID 用英文 |
| `HTTPClient` 卡住不返回 | 网络不通/证书问题 | 先用手机浏览器打开 `api.deepseek.com` 确认网络通 |

## 9. 安全提醒

1. **API Key 等于钱**，泄露了别人能刷你的额度。别发群、别贴图、别提交到公开仓库。
2. 代码里用 `WiFiClientSecure` + `setInsecure()`（跳过证书校验）只是为了让小白少踩坑，**仅限家里玩**；将来要放到公网请换成正规证书校验。
3. 麦克风会把你家里的话传到云端服务商那儿——这点心里要有数，别在机器人旁边说敏感信息。
