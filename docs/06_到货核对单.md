# 06 · 到货核对单（v2：N20 四驱 + 2S 锂电池 + 5A CC/CV 降压）

> 打印出来或存手机上。**核对完再拆包装、再接线**。
> v2 和 v1 最大的区别：**电池是 2S 锂电池（XT60 接口）+ 独立降压模块**，不再用 DFRobot 18650 电池座。

---

## 1. ⚠️ 上电第一件事：先激活 + 调成 5.0V

你买的是 **5A/75W 恒流恒压（CC/CV）模块**，带电压/电流两个电位器和三个状态灯。它有两个隐藏坑：

**坑 A：出厂可能"未激活"** → 接上电池输出端一直是 **0V**，你会以为模块坏了。
**坑 B：出厂电压不一定是 5V** → 不调直接接 ESP32 = 当场烧板。

| 步骤 | 做什么 | 判据 |
|---|---|---|
| 0 | **逆时针慢慢转电位器约 20 圈**（"激活"） | 听到极轻的"咔哒"声，或万用表开始有电压变化 |
| 1 | 模块**只接电池输入**，输出端空着 | 万用表 DCV 20V 量 OUT+/OUT− |
| 2 | 慢慢转"**电压调节**"电位器 | 调到 **5.00V**（4.95~5.05） |
| 3 | "**电流调节**"电位器**顺时针拧到底** | 限流最大 |
| 4 | 断电 → 接 ESP32 → 上电复测 | 带载仍 ≈5.0V；掉到 4.5V 以下 = 限流太小 |

**三个灯怎么看**：`恒压灯亮` = 正常；`恒流灯亮` = 电流被限（限流太小或负载太大，ESP32 会重启）；`充电灯/充满灯` 是它的充电器逻辑，当电源用可忽略。

**功率余量**：厂家标 75W（建议长期 ≤50W）、5A（建议 ≤4A）。你的峰值 5V×2.3A ≈ **11.5W / 2.3A**，只用了 1/4，很安全。

**⚠️ 别用它给电池充电**：没均衡、没过充保护，锂电有起火风险。充电用专门的 2S 平衡充。

## 3. 五个"一看就定生死"的丝印

1. **主控模组**：`N16R8`（不能 `N16`、不能 `MINI-1`）
2. **屏幕背面**：`ST7789`（240×320）
3. **降压模块电位器**：必须有 **2 个**（电压 + 电流），且输出已调到 **5.0V**
4. **OV2640**：有没有完整的 DVP 信号（PCLK/VS/HREF/D0~D7）
5. **TB6612 四路板**：电机输出是**端子**还是焊盘；STBY 是 1 个还是 2 个

任何一条不对，**先别上电**。

## 4. 到货当天 12 步

1. 拍照：主控丝印、屏幕背面、降压模块（两个电位器）、TB6612 端子、电池标签
2. 核对第 2 节的 BOM，缺件立刻找商家
3. 杜邦线**分袋贴标签**（20cm 母母 / 10cm 母母 / 20cm 公母 / 一转二）
4. 电池**先别插车**
5. **先单独调降压模块到 5.0V**（第 1 节），不接任何负载
6. 用万用表通断档测：电池 XT60 正负**不短路**
7. 装底盘：4 个 N20 + 轮子（先不接线）
8. 固定云台支架到最上层
9. 先做**第 1 关：空板点灯**（只插 UART 口 USB，不接电池）
10. 第 1 关过了，再接降压模块 → 上电池 → 测 5V
11. 按 [docs/03](03_分步测试指南.md) 一关一关走
12. 每加一个模块，在进度表上打勾

## 5. 叠层布局（9×9cm，从上到下）

```
┌─ 最上层：摄像头 + SG90 双轴云台（天线朝外那侧留空）
├─ 第二层：2.4 寸屏 / 超声波（车头方向）
├─ 第三层：ESP32-S3（天线朝外！）+ 四路 TB6612
├─ 第四层：5A 降压模块（朝外散热，别贴电池）
└─ 最下层：2S 锂电池（最重，压住重心）
```

**三条铁律**：
1. **ESP32 天线端朝外/朝上**，别被电池或铜柱夹在中间（不然图传掉线）
2. **电池在最下层**，重心低才不翻
3. **降压模块留 5mm 散热缝**，它会给 ESP32 供电、也会发热
