## 2. 五个"一看就定生死"的丝印

到货先只看这五处，其余可以边装边看：

1. **主控模组**：`N16R8`（不能是 `N16`、不能是 `MINI-1`）
2. **屏幕背面**：`ST7789`（240×320）
3. **TB6612**：AOUT/BOUT 是**螺丝孔**还是**排针**
4. **OV2640**：有没有 `XCLK` 这个针脚
5. **电池座**：有没有 `5V` / `3V3` 标注的输出排针

任何一条不对，先别拆包装，**拍张清晰照记录下来**（同时对照 [docs/01](01_接线总表.md) 第 3 节的模块引脚表）。

## 3. 到货当天 10 步

1. 拍照（上面五处丝印）
2. 拆包，按上面表格核对一遍，缺件立刻找商家
3. 杜邦线**分四个袋子**贴标签（20 母母 / 10 母母 / 20 公母 / 一分二）
4. 电池**先别装**
5. 万用表先**短接两支表笔**，记住基准读数（0.1~0.5Ω）
6. 装底盘：4 个电机 + 轮子 + 螺丝（先不接线）
7. 用雪弗板/舵机支架把**云台**固定到底盘前部
8. 先只做**第 1 关：空板点灯**（只插 UART 口 USB 线，不接任何模块）
9. 第 1 关过了再按 [docs/03](03_分步测试指南.md) 一关一关走
10. 每加一个模块，都在 [docs/03](03_分步测试指南.md) 的进度表上打勾

| **20cm 母母** | 80 根 | 摄像头 16、超声波 4、电机 8、5V/GND 干线 7 |

## 5. 车身布局建议（26cm 长，20cm 线够不够）

底盘 **26cm 长**，比你想象的宽松，但也意味着"从车尾到车头"距离长。建议这样摆：

```
车头 ←────────────────────────────────→ 车尾
[超声波][  屏幕  ] [ 云台+摄像头 ] [ ESP32 ] [ TB6612 ][ 电池座 ]
                                     ↑
                          主控放中间偏前，缩短到摄像头的距离
```

- **ESP32 放在车身中部偏前**，这样到云台的 16 根摄像头线用 20cm 够；
- 如果云台装在车头最前沿、ESP32 装在车尾 → 20cm 会紧张，**改成把 ESP32 往前挪**，或再买 10 根 25cm 母对母专给摄像头；
- **电池座放车尾**（最重，压住后轮，抓地更好）；
- 屏幕装车头做"脸"，离 ESP32 约 10~15cm，用 10cm 或 20cm 都行；
- 超声波装车头最前沿、**抬高到离地 5cm 以上**（太矮会一直测到地面）。
