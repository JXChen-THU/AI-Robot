## 0. 三条生死规则（违反任意一条都会烧东西或白折腾一晚）

| # | 规则 | 违反后果 |
|---|---|---|
| 1 | **摄像头、麦克风、屏幕、TB6612 的 VCC 走 3.3V；只有 ESP32 的 5V 脚、TB6612 的 VM、舵机红线、功放 VIN 接 5V** | 3.3V 器件进 5V → 当场烧 |
| 2 | **HC-SR04 供 3.3V**（宽压版可以）。如果你非要用 5V 供电，ECHO 必须先分压（1kΩ + 2kΩ），否则 5V 直接打进 ESP32-S3 | ESP32 引脚击穿，板子报废 |

## 1. 为什么引脚是这么排的（先讲清账，再动手）

### 1.1 这块板到底剩几个能用的脚

ESP32-S3 一共 45 个 GPIO，但这块 **N16R8** 板子上被吃掉一大半：

| GPIO | 状态 | 说明 |
|---|---|---|
| 26–32 | ❌ 永久占用 | 板载 SPI Flash |
| 33–37 | ❌ 永久占用 | **8MB OPI PSRAM**（N16R8 才有，你这份方案里提示得对）|
| 0 | ⚠️ 板载按键 | BOOT 键，只能当输入用 |
| 43 / 44 | ⚠️ 串口 | 焊死在 CP2102 USB-UART 上，留给串口监视器 |
| 19 / 20 | ⚠️ USB | 原生 USB D-/D+，改用普通 GPIO 后就不能插 USB 口 |
| 3 / 45 / 46 | ⚠️ 启动脚 | 上电瞬间的"电平"决定启动方式，必须让它们上电时为低/悬空 |

**结论：真正干净的引脚只有 25 个**（1,2,4~18,21,38~42,47,48）。
再用上 3、45、46（上电默认低，安全）和 19、20（放弃 USB 口），**总数 = 30 个**。

### 1.2 7 个模块要多少脚

| 模块 | 必须的引脚数 | 省无可省 |
|---|---|---|
| OV2640 摄像头 | **14** | D0–D7 + XCLK + PCLK + VSYNC + HREF + SIOD + SIOC |
| ST7789 屏幕 | **4** | SCL + SDA + CS + DC（RST、背光直接接 3V3）|
| INMP441 + MAX98357A | **4** | BCLK、WS 两个共用，麦克风 SD、功放 DIN 各一根 |
| TB6612 + 4 电机 | **4** | AIN1/AIN2/BIN1/BIN2 直接吃 PWM（PWMA/PWMB 接 3V3）|
| SG90 云台 | **2** | 水平、俯仰各一根 |
| HC-SR04 | **2** | TRIG、ECHO |
| 串口调试 | 2（保留） | 43 / 44 |
| **合计** | **30** | 正好等于 1.1 算出来的 30 |

## 2. 供电拓扑（照着插，别自己发挥）

```
        ┌──────────────────────────────┐
        │  DFRobot 双节 18650 电池座   │  开关拨到 HOLD（常开）
        │  两节 3.7V 串联 ≈ 7.4~8.4V   │
        └───────┬──────────────┬───────┘
                │5V            │3V3（不要用来带电机/舵机）
        ┌───────┴───────┐      │
        │ 5V 母排       │      │
        │ ├ ESP32  5V   │      │
        │ ├ TB6612 VM   │      │
        │ ├ 舵机 红线×2 │      │
        │ ├ 功放  VIN   │      │
        │ └ 1000µF 正极 │      │
        └───────────────┘      │
                               │
        ┌──────────────────────┴─────────────────────────────┐
        │ 3V3 母排（建议从 ESP32 板的 3V3 脚取，别从电池座取）│
        │ ├ 摄像头 3V3   ├ TB6612 VCC   ├ INMP441 VDD        │
        │ ├ 屏幕 VCC     └ HC-SR04 VCC                       │
        └────────────────────────────────────────────────────┘

        GND：以上所有模块的 GND、电池座 GND、ESP32 GND → 全部连通
             1000µF 负极接 GND
```

**为什么 3V3 从 ESP32 板取**：电池座的 3V3 是线性稳压，电流余量不明；摄像头峰值约 250mA、再叠加 WiFi 峰值，容易把 3V3 拉塌。ESP32 板上的 LDO 有余量。

**为什么要接电容**：电机启动瞬间电流是平时的 5–10 倍，电池座的 5V 会被拉低，ESP32 掉到 3V 以下就重启。1000µF 是把这几毫秒"垫"过去。

| 9 | `D0` | **GPIO 4** | `PIN_CAM_D0` | |

| 18 | `PWDN` | **GND**（直接插死） | 代码填 `-1` | 拉低=常开 |

> 引脚定义来源：标准 OV2640 18 针模块规格（[Cirkit 元件文档](https://docs.cirkitdesigner.com/component/0b4ab970-a770-4914-a067-22f83b3cadd1/ov2640-18-pin-board)）：1 GND / 2 VCC / 3 SCL / 4 SDA / 5 VSYNC / 6 HREF / 7 PCLK / 8 XCLK / 9-16 D0-D7 / 17 RESET / 18 PWDN。

**如果你数出来只有 16 针，别慌**：市面上有一批 16 针版本把 `PWDN` 和 `RESET` 在底板内部**直接拉死**了，只引出 16 根（少了 18 针里的 17、18 两脚）。这种**完全能用**，代码里本来就是 `-1`。

**唯一必须有的脚是 `XCLK`**。判断方法：
- 数针脚 + 看每个丝印，**能数到 `XCLK` → 能用**；
- 找不到 `XCLK` → 这块模块不是 DVP 接口（可能是 SPI 版/带 MCU 的串口版），**用不了，必须换**。

**其他可能的丝印别名**（叫法不同，是同一个信号）：`SIOC`=`SCL`、`SIOD`=`SDA`、`VS`=`VSYNC`、`RESET`=`RST`、`MCLK`=`XCLK`。

## 4. 电容和线材

### 4.1 电容怎么接（免焊接版）

1. **1000µF / 16V 电解电容**：**正极（长脚）→5V，负极（短脚，外壳上有「−」条纹）→GND**。方向别反，反了会鼓包甚至炸开。
2. **免焊接怎么插**：电容的两条腿没有杜邦头，插不进排针。正确做法是——找两根**母对母**杜邦线，把电容的腿插进母头这一端，插紧后用热熔胶把开口封住固定（你有热熔胶），另一端母头再插到 5V / GND 排针上。
3. **接几个合适**：
   - 必接：**1 个**在主 5V 母排上（这就是设计里那 1000µF）；
   - 强烈建议：**再并 1 个**在两个舵机的 5V 供电处（离舵机越近越好，压住舵机启动的跌落）；
   - 剩下的当备用（电解电容有寿命，几年后容量会掉）。
   - 并 2 个 = 2000µF，**完全没问题**，不会"太大"。注意是**并联**（正接正、负接负），**绝不能串联**。
4. 所有电容的负极必须和整车**共地**。

### 4.2 杜邦线长度清单（★ 10cm 只能覆盖一部分）

线长不够是新手最常见的"装了拆、拆了装"原因。按下面这张表备线：

| 连接 | 建议长度 | 10cm 够不够 |
|---|---|---|
| 摄像头 16 根（装在云台俯仰舵机上，**会跟着转头**） | **20~25cm**，且要留出转动余量 | ❌ 不够 |
| 4 个 TT 电机 → TB6612（电机在底盘四角） | **15~25cm** | ❌ 不够 |
| 电池座 5V/GND → 一分多母线 → 各模块 | **15~25cm** | ❌ 不够 |
| 超声波 4 根（装车头最前面） | **15~20cm** | ❌ 勉强 |
| 屏幕 8 根（装车头/胸口） | 10~15cm | ✅ 够 |
| 麦克风 6 根 | 10~15cm | ✅ 够 |
| 功放 6 根 | 10~15cm | ✅ 够 |
| 舵机 6 根（舵机就在云台上） | 10cm | ✅ 够，但供电线要单独拉回 GND |
| TB6612 信号 8 根（靠近主控） | 10cm | ✅ 够 |

> 结论：**10cm 的线拿来做"短距离信号线"很合适，长距离（摄像头/电机/电源）必须换 20cm 以上。**
> 切记：**宁可换一根长线，也不要把两根短杜邦线串起来**——串接的接触点是"车自己随机重启"的头号元凶。

### 4.2.1 如果要"一种长度通吃全车"：买 **20cm 母对母**

| 长度 | 评价 |
|---|---|
| 10cm | ❌ 摄像头、电机、电源母线不够 |
| **20cm** | ✅ **最优解**：全车都能走通，还能留出云台转动的余量；再长就只剩坏处了 |
| 30cm | ⚠️ 能用但没必要：线越绕越乱，而且摄像头那 14 根数据线**越长越容易花屏** |
| 50cm | ❌ 摄像头 DVP 并口线太长会直接导致图传花屏/黑屏；电源线也跌压 |

**数量建议：20cm 母对母买 60 根**（约 10~15 元）。需要 20cm 的大概是：摄像头 16 根 + 电机 8 根 + 电源母线 6 根 + 超声波 4 根 ≈ 34 根，剩下的当备用（杜邦线是消耗品，插拔几十次就会松）。其余短距离用 10cm 就够，见下表。

**10cm 的线不是废的，它有明确岗位（合计约 40 根）**：

| 用途 | 根数 |
|---|---|
| 屏幕 8 根（含 RST/BLK 接 3V3 的两根短跳线） | 8 |
| 麦克风 6 根 | 6 |
| 功放 6 根 | 6 |
| 舵机 6 根（2 个 × 3 根） | 6 |
| TB6612 信号 4 根 + PWMA/PWMB/STBY 接 3V3 的 3 根跳线 + VCC/GND | 9 |
| 3V3 / 5V 一分多母线短跳线 | 5 |
| **小计** | **≈ 40** |

所以：**10cm 的线留着当"短接线 + 调试耗材"，20cm 的当"主力干线"，两种各司其职**。
只有一种情况该退：**那 120 根如果全是"公对公"**（没有母对母）——公对公是给面包板用的，本项目不用面包板，那就真的用不上，退掉换"母对母"或"三型混合包"。

**买线时注意**：选 **24AWG 铜芯**（商品页会写"24AWG 纯铜"），别买 28AWG 铝芯——电阻大、电机一启动就跌压。

> **摄像头的备用方案**：万一 20cm 线跑 VGA 出现花屏/条纹，把 `04_camera.ino` 和 `07_main.ino` 里的
> `xclk_freq_hz = 20000000` 改成 `10000000`（10MHz），长线容忍度立刻翻倍，代价是帧率略降。这比重接线快得多。

### 4.2.2 线型怎么选（母对母 / 公对母 / 公对公）

判断口诀：**看你要插进去的那一端是"针"还是"孔"——针要配母，孔要配公。**

| 线型 | 一端 | 另一端 | 什么时候用 | 本项目要几根 |
|---|---|---|---|---|
| **母对母 (F-F)** | 母（套住针） | 母（套住针） | 两头都是**排针（公针）**时。模块排针 ↔ ESP32 排针全是这种 | **主力，60 根** |
| **公对母 (M-F)** | 公（插进孔） | 母（套住针） | 一头是**母座**时。最典型的是 **SG90 舵机插头（母座）**——它的信号线要接到 ESP32 的公针上，必须用公头那端插进舵机 | **10 根**（2 个舵机各 3 根 + 备用）|
| **公对公 (M-M)** | 公 | 公 | 两头都是母座（面包板、母排）。**本项目没有面包板，用不上** | 0 |

**常见的两个误区**：
1. 以为"混合包最保险"——其实公对公在这个项目里一根都用不到，混合包等于浪费 1/3。
2. 以为舵机也能用母对母——不行。舵机插头本身就是母座，母对母线两头都套不进去，插不上力。

**如果只能买一种**：买**母对母**。舵机那 6 根可以先用套件里通常自带的"舵机延长线（一分三）"顶替，或者把舵机插头剪掉单根用（**不推荐，要焊**）。

> 补充：TB6612 红板如果是**螺丝端子版**（AOUT1/AOUT2/BOUT1/BOUT2 是 4 个螺丝孔），那么 4 个电机直接拧进去，**再省 8 根线**。如果是排针版才需要杜邦线。

## 5. ⚠️ 这两个 Type-C 口，用哪个？

你的板子有两个 Type-C。**必须记住这条**：

| 口 | 丝印 | 用途 | 能不能插 |
|---|---|---|---|
| UART 口 | `UART` / `COM` | **烧录 + 看串口**（走 CP2102 芯片，最稳） | ✅ 只插这个 |
| USB 口 | `USB` / `USB-OTG` | 原生 USB | ❌ **平时别插** |

原因：超声波用的 **GPIO 19 / 20 就是原生 USB 的数据线 D-/D+**（为了凑够 30 个引脚，只能征用它们）。一旦插上 USB 口，电脑会和超声波抢这两根线。

**Arduino IDE 里必须确认**（细节见 docs/02）：
- `USB CDC On Boot` → **Disabled**（保持默认）
- 端口选 **带 COM 的那个**（CP2102）

## 6. 上电前的 12 项检查（花 5 分钟，省一晚上）

> 顺序很重要：**先不插电池**，用万用表通断档检查。

- [ ] 1. 电池座开关在 **HOLD**？两节电池**方向一致**（尖头同向）？
- [ ] 2. 5V 母排和 GND 之间**不短路**（通断档不响）？
- [ ] 3. 1000µF 正负极没接反？
- [ ] 4. 摄像头 3V3 接的是 3V3，不是 5V？
- [ ] 5. INMP441 的 VDD 是 3V3？L/R 是 GND？
- [ ] 6. TB6612 的 VM=5V、VCC=3V3、STBY=3V3、PWMA/PWMB=3V3？
- [ ] 7. 屏幕 RST 和 BLK 都接 3V3 了？
- [ ] 8. 舵机红线接的是 5V，不是 3V3？
- [ ] 9. 超声波 VCC 接的是 3V3？
- [ ] 10. 所有 GND 都接到同一个电网了？
- [ ] 11. **先只插 UART 口 USB**，上电看串口有没有输出（此时不要装电池）
- [ ] 12. 确认串口正常后，再装电池、拨 HOLD

**第一次上电建议把车架空**（轮子不落地），避免接错线时车自己冲出去。

### 6.1 万用表怎么买、怎么用（零基础版）

**买什么**：数字万用表，25~40 元（如 DT9205A、优利德 UT136B+ 入门款）。
**必须有的三个档**：`DCV 20V`（量电压）、`通断/蜂鸣 ⏰`（量通断）、`Ω 电阻`。
**表笔**：万用表**自带红黑一副，不用另买**。标准表笔的针尖能抵住 2.54mm 排针测量，本项目够用。
想要更顺手，可以加 5~8 元一副「**鳄鱼夹转香蕉头表笔线**」——夹住排针/杜邦线测，不用一直用手抵着。

⚠️ **别买错**：几十块的「**测电笔**」只能亮灯看"有没有电"，**不能量电压、不能测通断**，本项目不能用。

**本项目的三个动作用法**：

| 动作 | 档位 | 表笔怎么放 | 正常结果 |
|---|---|---|---|
| 查短路 | 通断（蜂鸣） | 红笔放 5V 排针，黑笔放 GND 排针 | **不响**。响 = 有短路，先别上电 |
| 查线通断 | 通断（蜂鸣） | 一头插线这端，一头插线那端 | 响 = 线是通的；不响 = 线断了/没插到底 |
| 查电压 | DCV 20V | 红笔 5V/3V3，黑笔 GND | 5V 排针 ≈ **4.9~5.2V**；3V3 排针 ≈ **3.2~3.35V** |

测之前**先看表笔插孔的对错**：黑笔插 `COM`，红笔插 `VΩmA`。档位拧到对应档再测，别用电阻档去量带电的电路。

**关于 DT830B 这类"没有蜂鸣"的表**：DT830B（约 15 元）完全能用，它的 `DCV 20V` 档和 `Ω 200Ω` 档都在。只是**通断靠看数字、不靠听声**：

| 读数 | 含义 |
|---|---|
| `0.0 ~ 1.5` | 通（线是好的） |
| `1` 或 `OL` | 不通（断了 / 没插到底） |
| 测之前先把两支表笔尖**碰在一起** | 看到 `0.1~0.5` → 这是表笔自身的电阻，属正常基准 |

> 如果还在挑：**多花约 10 元买带蜂鸣的型号（DT9205A 之类）会省心很多**——量通断"嘀"一声就行，不用盯数字。但 DT830B 不是不能用。
> DT830B **没有自动关机**，用完一定把旋钮拧回 `OFF`，否则 9V 电池几天就耗光。

## 7. 出问题时的第一反应

| 现象 | 90% 的原因 |
|---|---|
| 串口完全没输出 | 插了 USB 口 / 没选对 COM / USB CDC 被打开了 |
| 串口有输出但反复重启 | 5V 电流不够（舵机和电机同时动）→ 降低 PWM、加电容 |
| 屏幕白屏/花屏 | RST 没接 3V3，或 User_Setup.h 引脚和这张表不一致 |
| 摄像头初始化失败 | D0–D7 有一根插错/没插到底；或 RST 悬空 |
| 麦克风没声音 | L/R 没接 GND；或 VDD 接错 |
| 舵机抖动/乱转 | 舵机接了 3V3；或者和电机共用 5V 被拉低 |
| 电机只往一个方向转 | PWMA/PWMB 没拉到 3V3 |

更多排查见 [docs/04_排错手册.md](04_排错手册.md)。

## 8. 备用方案（如果你后面想加东西）

本方案 **30 个引脚用得一个不剩**。想加蜂鸣器、编码器、第二路传感器，只能二选一：

- **方案 B1（推荐）**：超声波改"单线模式"（TRIG 和 ECHO 都接 GPIO 19，靠代码切换输入输出），**释放 GPIO 20**。
- **方案 B2**：放弃屏幕（改用手机网页当表情面板），**一次释放 4 个引脚**。
- **方案 C**：买一块 PCA9685 舵机板（约 8 元），用 2 根 I2C 线换 16 路舵机，**释放 2 个引脚**。

**编码器（TT 电机后面那 6 根线）本次不接**，代码里也不用，把它们用扎带收好即可——不影响任何功能。
